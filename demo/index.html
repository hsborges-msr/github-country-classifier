      The classifier reads only the profile's location, company, blog, email domain, Twitter handle and bio; it never reads the login or the name. It was calibrated on users who declare a location, so answers for profiles without one are less reliable: treat each answer as an estimate, useful in aggregate. Users below the minimum confidence, or whose profile has none of those fields, are shown as indeterminate.
